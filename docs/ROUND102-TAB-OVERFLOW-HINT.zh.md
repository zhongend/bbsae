# Round 102 — 预览左右分栏标签溢出提示

> 版本 `0.99-hotfix66`。未启动客户端截图；行为由纯窗口算法测试与全量回归验证。

## 1. 问题

预览框左侧是分区标签（效果库 / 素材箱 / 预设 / 回放），右侧是检查器分区
（调色 / 图层 / 影视 / 蒙版 / 效果 / 文字 / 合成 / 输出）。面板被拖窄时，
`UICompTabBar` 只显示前 N 个标签，其余 `setVisible(false)`，右边缘只有一个很小的 `»`。

第一性原理上这是 **false affordance**：界面只呈现了“已显示的分区”，却没有任何
“还有分区存在”的状态。更糟的是活动分区被隐藏时，唯一线索是 `»` 下一像素高的蓝线，
用户会直接认为功能/分区消失。

## 2. 方案

### 2.1 可见窗口始终包含活动分区

`CompUi.tabStripWindow(widths, available, active, arrowWidth)`：

- 总宽放得下 → 全部显示；
- 否则为左右箭头各预留 `arrowWidth`；
- 从起点贪心计算能放下的数量；
- 活动分区在首页窗口内 → 从 0 开始；
- 活动分区在窗口之后 → 窗口向前滚动到包含它；
- 返回 `{first, endExclusive, hasLeft, hasRight}`。

`UICompTabBar` 在 resize、addTab、select、以及检测到活动页变化时重算窗口；
活动分区自己的标签会滚入可见区，因此不再出现“标签不可见但下划线在”。
隐藏标签不参与绘制/命中，避免越界抢点击。

### 2.2 三种“还有内容”的信号

1. **渐隐渐变**：有隐藏标签的一侧，从标签文字区域渐变到面板底色（`0x0012161D` →
   `0xE612161D`），视觉上像内容延伸到栏外。
2. **带数量的呼吸箭头**：`«N` / `»N`，N 是该侧隐藏的分区数；鼠标悬停提高亮度，
   点击翻到上一/下一分区；动画关闭时仍显示静态提示。
3. **活动下划线**：即使自动滚动后活动分区一般已可见，隐藏活动页时仍保留边缘下划线
   作为兜底。

左右两侧可以同时溢出：左箭头命中区为栏首 20 px，右箭头为栏尾 20 px，互不影响。

## 3. 边界与兼容

- 无溢出时不会画渐变/箭头，标签布局与原版一致；
- 保留 `CompUi.tabStripLayout(...)` 供既有测试和调用，不改语义；
- 标签仍是绝对定位的 BBS `UITextTab`，活动下划线、hover、press 动效不变；
- 呼吸动画遵循 `CompPrefs.animating()`，用户关闭动效后只有静态渐变 + 计数。

## 4. 验证

- 新增 `CompUiTabWindowTest`：
  - 宽栏显示全部；
  - 首页只有右侧溢出；
  - 末页滚动到窗口并只有左侧溢出；
  - 中间页可能两侧同时溢出；
  - 40–400 px 的所有宽度、所有活动页组合下，活动分区必须落在窗口内；
  - 空栏不产生窗口。
- 全量测试：**173 套件 / 1047 项 / 0 failures / 0 errors / 1 skipped**。
