# Round 73 — bbsae 自己的回放模式 / 多选提示 / 摄像机按钮

本轮针对新需求的第一批：bbsae 回放不再打开 BBS 的影片回放界面，模型与文字/相机在同一个
bbsae 预览里；同时移除预览里的看穿按钮、补多选提示。

## 1. bbsae 回放模式

之前「回放」模式显示的是 `UIReplayModePanel`，即 BBS 原生影片回放列表/属性，和真实世界绑定。
现在：

- 「合成 / 回放」切换仍然在顶栏；
- 回放模式保留 **bbsae 正常 dock**：左侧回放列表、中间合成预览、右侧检查器、下方时间轴；
- 隐藏 BBS 原生回放面板，不再打开真实影片回放列表；
- 回放 transport 直接驱动 bbsae 的 `time`，播放/上一帧/下一帧/时间码都来自合成器；
- 回放模式自动切到左栏「回放」页；
- 进入回放模式时临时隔离图层：只保留 bbsae 3D 模型、文字层、摄像机；
  退出时恢复所有图层的原可见性。

这样回放预览里能看到：
- BBS 模型（bbsae 相机渲染）；
- 文字图层；
- 摄像机 HUD / 透视信息；
- 3D 网格与 bbsae 预览组件。

截图：`docs/verify/round72-bbsae-replay.png`（真实运行，模型、文字、相机同时可见）。

## 2. 模型可见性

- 独立模型改为每图层独立 FBO，避免共享 actor target 被下一次 bake 覆盖；
- 源缓存跳过 independent 模型层，模型每帧直接渲染；
- 合成阶段新增最终模型 overlay，模型在普通图层之后合成；
- 回放模式隔离装饰性卡片/背景，确保新导入的模型不会被上层卡片盖住；
- 新模型默认 240×240、scale 2。

## 3. 摄像机按钮

- 预览框右侧的「看穿摄像机」按钮隐藏；
- 改为设置 → 显示 → 「看穿摄像机」开关；
- 数字键盘 0 仍然可用。

## 4. 多选提示

- 选择多个图层时自动切到检查器「图层」页；
- 状态栏提示「已多选 N 个图层 · 可预合成 / 合并 / 删除」；
- 设置 → 显示新增「上下文操作提示」，可关闭这些提示。
