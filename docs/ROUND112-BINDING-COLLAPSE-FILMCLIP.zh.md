# Round 112 — 绑定、影片片段与折叠预合成

> 版本 `0.99-hotfix77`。未启动客户端截图；全量 182 套件 / 1127 项 / 0 failures / 1 skipped。

## 1. 合成器效果无法绑定（BBS 影片编辑器）

### 现象

在 BBS 原版影片编辑器里打开合成器，选中图层后「绑定 / 跟踪」区域看不出如何操作；
切换类型、打开启用都没有效果，等于无法绑定。

### 根因

| # | 问题 |
| --- | --- |
| 1 | 类型是“循环按钮”，目标是**自由文本 id**；回放要填 Replay 内部 id、图层要填图层 id，用户无从得知 |
| 2 | 绑定分区默认折叠，而图层长页也默认折叠，入口几乎不可见 |
| 3 | `BindingResolver` 只查 BBS film controller 的实时实体表；导出/暂停/刚打开工程时可能为空，绑定静默失效 |
| 4 | 类型为 `none` 时“启用”没有提示，是空操作 |

### 修复

- 下拉选择类型：`无 / 影片回放实体 / 合成图层 / 屏幕中心（摄像机）`。
- 目标改为候选列表（名称 + id）：
  - 回放实体来自当前影片 `film.replays`；
  - 图层来自当前合成 `doc.layers`（排除自己）；
  - 摄像机是屏幕中心锚点。
  选中后自动 `enabled = true`，状态栏说明绑定结果。
- 增加目标校验行：replay 被删/重建、图层被删时提示重新选择。
- 分区默认展开。
- `BindingResolver`：
  - 新增 `setFilm(film)`，面板绑定/关闭时同步，避免读旧影片；
  - 优先实时实体的真实眼高位置；
  - 没有实时 controller 时，按合成时间（秒 × 20 = film tick）读取 replay 的
    `x/y/z` 关键帧通道并投影。这样导出与预览使用同一位置，不再“编辑器里对、导出跑偏”。

## 2. 进入存档自动创建合成器片段

### 现象

每次进入存档，BBS 影片编辑器的摄像机轨道自动出现一段「合成器」片段。

### 根因

`bind` / `selectReplay` / 时长修改等“视图/编辑”路径调用 `CompositionClip.ensureForFilm`，
而它会**创建**片段。打开合成器是视图动作，却修改了影片文档。

### 修复

- `CompositionClip.findForFilm`：只查。
- `CompositionClip.updateForFilm`：只更新已有片段的 tick/duration/title，**绝不创建**。
- 面板所有绑定/切回放/改时长路径改用 `updateForFilm`。
- 显式创建入口：
  - 「合成」页「＋ 添加到 BBS 影片轨道」；
  - 导出时的 `prepareForExport`（显式动作）。
- 「合成」页显示当前是否已加入影片轨道，并提供「从 BBS 影片轨道移除」。
- 未加入时合成器自身预览/独立导出不受影响。

## 3. 预合成添加效果后大小比例跳变

### 根因

`usesParentCameraForPrecomp` 原本要求：

```java
layer.collapse && masks.isEmpty() && effects.isEmpty() && styles.isEmpty()
```

折叠（Collapse）是**投影选择**：嵌套 3D 内容直接进入父相机空间。加任何一个效果后条件
变 false，投影从“父相机折叠”切到“子合成自己的相机压平”，嵌套内容的大小/比例瞬间变化。

### 修复

- 折叠只取决于 `layer.collapse`，与像素操作无关。
- 折叠的预合成跳过 layer-local 烘焙（`shouldBake3D` 返回 false）：
  - 内容已经是父合成空间画面，效果/蒙版/样式直接在该空间处理；
  - 避免把父空间画面再放进 layer-local 光栅后二次投影。
- 未折叠预合成仍走 layer-local 烘焙（效果贴在平面上）。
- 检查器文案改为“折叠始终生效；蒙版/效果/样式在合成后的画面上处理”。

## 4. 验证

- 新增 `CollapsedPrecompTest`（4）：
  - 默认不折叠；
  - 加效果/蒙版/样式不改变嵌套相机；
  - 折叠预合成跳过 layer-local 烘焙；
  - 普通预合成仍烘焙。
- 全量：**182 套件 / 1127 项 / 0 failures / 0 errors / 1 skipped**。
- 建议实机：
  1. 影片编辑器打开合成器 → 绑定区选择回放实体 → 拖动 replay，HUD 图层跟随；
  2. 打开/关闭合成器、切换 replay，影片轨道不应凭空多出片段；
  3. 3D 预合成开启折叠 → 记录尺寸 → 加 glow → 尺寸不应跳变。

## 5. 边界

- 折叠预合成上的效果在合成空间执行；需要图层本地空间的效果请关闭折叠。
- 回放绑定的模型级回退使用近似眼高 1.6；实时 controller 可用时用真实实体。
- 已存在的自动创建片段不会自动删除（可能是用户真正的合成）；用「从 BBS 影片轨道移除」。
