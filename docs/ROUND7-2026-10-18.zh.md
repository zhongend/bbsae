## 0. 先读结论

1. **预览选择框现在是真的变换手柄**：四角等比缩放、四边单轴缩放、顶部旋转柄；
   命中半径 12px，拖动时状态栏实时显示缩放百分比/角度。null 与摄像机改为屏幕空间
   小 gizmo（26px 半径），不再画一个没有意义的 100×100 内容框。
2. **调整层**：渲染顺序改为"以调整层为边界分段排序 3D 图层"，调整层永远只处理
   它下面已经累积的像素；调色页新增"为整个合成添加调色调整层"。
3. **预合成**：新建预合成图层会自动创建真实子合成；双击轨道/右键"进入预合成"；
   空子合成会画占位框而不是完全消失；`precomposeSelected` 只移动所选图层。
4. **摄像机**：`rotationX/rotationY` 真正参与 `lookAt` 计算；`cameraZ` 与 `z` 回退兼容；
   摄像机视图内滚轮推拉、Alt+滚轮改 FOV；**3D 网格不再逐像素画**（这是卡顿主因）。
5. **Alt+滚轮**：不再依赖 `Screen.hasAltDown()`，直接读 GLFW 的左右 Alt；同时兼容
   横向滚轮事件；缩放后状态栏显示百分比。
6. **调色**：新增色相旋转与褪色/胶片；白平衡改为乘法（不再整体平移亮度）；
   色轮/曲线/数值仍全部可关键帧。
7. **效果覆盖测试**：`EffectCoverageTest` 遍历注册表，任何一个"只在 UI 里存在"的
   效果都会让测试失败。
8. **3D 空间**：预览工具栏新增一键"进入 3D 空间"（世界底图 + 透视摄像机 + 地面网格）。
9. **轨道遮罩**：原来要求手输图层 id，现在和父级一样是图层列表选择器，选中后自动
   开启"使用遮罩"。
10. **文字换行**：CJK / 超长单词按字符断行，不再溢出文本框。
11. **摄像机视图内拖动**：摄像机在摄像机视图里是"眼睛"，自身 gizmo 会落到近裁剪面后；
    现在把视图中心 40px 当作它的拖动命中区，因此可以直接在摄像机视图里平移机位。

## 1. 关键根因与修复

### 1.1 预览方框"没作用"

旧代码其实已经画了 8 个手柄，但：

- 命中半径 10px，手柄只有 3px，实际很难点中；
- null / camera 图层用的是 100×100 内容框，看起来像装饰；
- 拖动过程中没有任何数值反馈，用户无法判断是否生效。

修复（`UICompositorPanel` 预览匿名元素）：

- `handleAt` 命中半径 12px；角柄 5px、边柄 3px、旋转柄 5px；
- `selectionCorners` 对 `null`/`camera` 返回锚点周围 26px 的屏幕空间方框；
- 缩放/旋转拖动实时 `setStatus("缩放 X 120% Y 90%")`；
- 3D 图层仍然用屏幕距离比例做等比缩放，避免投影后局部坐标失真。

### 1.2 调整层

渲染顺序（`CompRenderer.orderLayersFor3D`）以前会把**所有** 3D 图层跨调整层重排，
导致调整层上面的 3D 图层可能被排到调整层下面，从而被"调整"到。现在按调整层切段，
每段内部才按深度排序。

`applyAdjustment` 的语义保持不变：在调整层所在的栈位置，对当前 accumulation 应用
效果链，因此只影响其下（更早绘制）的图层。新增 `addGradeAdjustment()` 一键创建
全合成调色调整层。

### 1.3 预合成

- `addLayer("precomp")` 以前只在工程已有第二个合成时才设置 `precompId`，单合成工程
  创建出来是空引用 → 什么都不画。现在总是 `addComp("precomp_N")` 并指过去。
- `precomposeSelected()` 以前会把 `solo` 图层一起搬走，并留下失效选中项；现在只移动
  当前选中图层，预合成图层继承原图层的 in/out。
- `LayerContentRenderer.drawPrecomp`：空子合成画占位框；嵌套渲染前 `batcher.flush()`，
  防止外层已排队的四边形被 flush 进子合成的 FBO。
- 轨道双击（350ms 内同一行）或右键"进入预合成"进入子合成；面包屑返回。

### 1.4 摄像机卡顿与逻辑

卡顿根因：`render3DGrid` 每帧对每条网格线**逐像素**调用 `batcher.box(1×1)`。
一个 700×400 的预览、约 100 条线 = 每帧 3–4 万个 quad，摄像机一开就掉帧。

修复：

- 网格步长 200px、粗线段（6px 一段、3×1.5px quad），线数 ~40；
- 普通选择框线改为 2px 步长 + 2×2 quad；
- `setup3D` 支持自由摄像机（`cameraLookAt=false`）的 X/Y 旋转与 Z 滚转；
- `cameraZ` 为 0 时回退到图层 `z`，再回退到默认焦距；
- 摄像机视图内滚轮推拉（改 `cameraZ`）、Alt+滚轮改 FOV；
- 近/远裁剪、俯仰/偏航、FOV 全部进入检查器并可关键帧。

### 1.5 Alt+滚轮

`Window.isAltPressed()` 走 `Screen.hasAltDown()`，在 BBS dashboard panel 中不可靠。
`UICompTrackTimeline` 现在直接用 `GLFW.glfwGetKey` 读左右 Alt/Ctrl/Shift，并把
`mouseWheelHorizontal` 作为回退。缩放后状态栏显示 `时间轴缩放 150%`。

### 1.6 调色

- 新增 `hue`（色相旋转，绕中性轴旋转矩阵）与 `fade`（褪色/胶片）；
- 白平衡由加法改为乘法，避免高光被整体推亮；
- 顺序：曝光 → 白平衡 → Lift/Gain/Gamma → 对比度 → 五点曲线 → 色相 →
  饱和度/自然饱和度 → 褪色 → 截断；
- `applyGradePreset` 重置 hue/fade。

## 5. 建议的实机验收清单

1. 打开合成器 → 选一个图层 → 拖四角/四边/顶部旋转柄，状态栏应出现百分比/角度。
2. 新建调整层 → 加"亮度对比度" → 只影响其下图层；上层不受影响。
3. 新建预合成图层 → 应出现"空预合成"占位框；双击轨道进入；放一个纯色后返回，
   预合成图层应显示该纯色。
4. 新建摄像机 → 打开"进入摄像机视图" → 旋转 X/Y 数值应改变画面；滚轮推拉、
   Alt+滚轮改 FOV。
5. 时间轴上 Alt+滚轮 → 状态栏出现"时间轴缩放 xx%"。
6. 调色页 → 色轮/曲线/色相/褪色都应即时改变预览。
7. 图层轨道头：眼睛、锁、3D 徽标、父子级链条四个按钮都要能点。

## 4. 下一步（给接手的 AI）

1. **3D 模型空间**：当前 3D 空间是"合成平面 + 透视摄像机 + 世界底图"，还不是
   BBS 模型编辑器那种可摆放方块/模型的场景。下一步建议：
   - 新增 `CompLayer.type = "model"`，字段 `modelId`（BBS model 路径）、`pose`；
   - 在 `LayerContentRenderer` 里用 BBS 的模型渲染器画到 layer FBO；
   - 摄像机沿用 `setup3D` 的 view/projection，不需要第二套投影。
2. **预览缩放/平移**：目前预览固定 fit，可加滚轮缩放 + 中键平移 + 100%/Fit。
3. **多选轨道 / 框选 / 波纹删除**。
4. **效果补充**：扫描线、故障 glitch、鱼眼、VHS、镜头光晕。
5. **3D 手柄**：角点缩放目前是屏幕距离比例，理想做法是射线与图层平面求交。
