# Round 37 — 3D 空间的效果完整性（0.20.4）

这一轮从“一个像素效果需要什么才能完整显示”开始。答案不是“调用 shader”，而是：

1. **支持域（support region）**：模糊/发光/投影会采样图层矩形以外的像素，栅格必须有足够留白，
   否则效果在边界被裁掉；
2. **坐标系**：效果、样式、遮罩都是图层自己的像素属性，必须在**层空间**、投影之前应用；
3. **只应用一次**：层空间烘焙和组合阶段的二次应用必须二选一（0.20.3 已修）。

## 1. 3D 效果被图层矩形裁掉

3D 图层走 `CompLayerSourceCache`：内容先画进一个**图层矩形大小**的 FBO，效果再在这个 FBO 上
运行，最后投影。模糊半径 40 的发光只能采样到矩形内部，边界外是“没有像素”，于是发光在图层
边缘被切成硬边——看起来像“效果没生效”或“只生效了一半”。

修复：`EffectPadding.of(layer, frame)` 计算效果核的最大支持半径：

- 模糊/盒式模糊/方向模糊 radius + 2；
- 发光 radius + 2；投影 distance + softness + 2；描边 width + 1；
- RGB 分离 amount；置换/膨胀/收缩/扭曲/波浪/湍流 amount；
- 径向模糊 amount × 较长边；故障 amount；
- 图层样式：投影 distance + blur，外发光 size，描边 size；
- 中性/禁用效果不占留白；上限 512 px。

`CompLayerSourceCache.bounds()` 把这个留白加到栅格矩形上。栅格仍然是层空间，只是多了透明
边缘；效果可以完整衰减，投影/视口/导出三处一致。

### 代理分辨率

栅格会被 `MAX_EDGE` 限制到较小分辨率，而模糊半径的单位是**栅格像素**。同样 40 px 的发光，
在半分辨率栅格里视觉上会变成 80 px，而且留白只有一半宽，又会裁切。

`scaleEffectForRaster()` / `scaleStyleForRaster()` 在应用前把所有像素半径参数从图层像素换算成
栅格像素（半径 × scale）。这样：

- 视觉半径保持图层像素不变；
- 留白（图层像素）在栅格里的宽度正好等于换算后的核半径；
- 原始 `CompEffect` / `CompStyle` 不被修改。

## 2. 图层样式没有进入 3D 图层

`StyleRenderer` 原来只在 `renderCompToFbo()` 的**投影之后**运行；3D 工作台则完全不跑样式。
投影后的阴影是屏幕空间的，相机一动就和图层脱节；3D 工作台里干脆看不到。

修复：`CompLayerSourceCache` 在**效果之后**应用 `layer.styles`（顺序与 2D 管线一致：内容 →
遮罩 → 效果 → 样式），样式因此烘焙进层空间栅格：

- 视口、相机视图、导出看到的是同一份像素；
- 投影之后不再重复应用样式（`effectsBaked` 现在表示“非深度效果 + 样式已烘焙”）；
- 只有源缓存不可用（回退到直接路径）时，才在投影后跑一次样式。

`GRADIENT_OVERLAY` 的 `EffectSpace.of(layer, world, context)` 仍然使用样式自己的空间映射；
对 3D 图层是 identity，渐变覆盖图层栅格，不会随相机滑动。

## 3. 3D 图层的遮罩被忽略

`renderCompToFbo()` 的遮罩分支条件是 `is2D`，所以 3D 图层的 masks 从来没被应用；3D 工作台
也没有遮罩。遮罩和效果一样是图层像素属性，应该在层空间、效果之前应用。

修复：

- `applyPixelOps()` 在效果之前调用 `MaskCache.get(layer, rasterWidth, rasterHeight, world, frame)`，
  把遮罩 alpha 乘进栅格；
- `world` 是“层局部像素 → 栅格像素”的 scale/translate，遮罩点仍在图层局部坐标；
- 遮罩先于效果，所以发光/描边可以像 2D 一样扩散到遮罩外；
- 只有遮罩的 3D 图层也会走 `renderBaked3D()`（条件加入 `masks`），否则它仍会走直接路径而
  绕过遮罩；
- 源缓存签名加入 mask 几何/羽化/扩展/不透明度，改遮罩会重建栅格。

## 4. 仍然属于“组合”而非“层像素”的东西

- **轨道遮罩**：需要另一图层的栅格与两者的相对变换；3D 透视下不是仿射映射，仍只在 2D 路径
  应用。
- **混合模式**：发生在合成阶段，本来就不该烘焙进层。
- **深度效果**（depth_fog / depth_dof / depth_matte）：需要实时世界深度；3D 工作台的栅格没有
  这份深度，仍在相机视图/最终渲染（有 `SceneDepth` 时）应用。自由视口里深度效果不会显示，
  HUD 的草稿提示仍然成立。
- **代理分辨率**：像素半径已经按栅格比例换算，视觉半径保持图层像素；但 `PassRenderer` 的
  模糊半径上限是 200 栅格像素、`EffectPadding` 上限是 512 图层像素，极端大半径仍会被这两个
  上限截断。
- **形状/文字的细节**在代理栅格缩小后会损失采样精度，这是代理分辨率的固有取舍。
