# Round 31 — 0.19.1：效果库减负、摄像机提示与界面光效

> 这一轮只处理“界面读起来累”和“操作预期不一致”，不新增效果渲染通路。
> 第一性判断：编辑器是长时间阅读的工具，任何装饰都必须先让信息更清楚。

## 1. 效果库不再拥挤

旧版效果库同时在两处展示“效果长什么样”：

- 底部一块 56 px 的预览卡；
- 每一行左侧 16×16 的缩略图 + 26 px 缩进。

在 190 px 的侧栏里，这两项占了接近 40% 的横向/纵向预算，而 16 px 的缩略图实际上无法辨认
模糊、置换、色彩映射的差异。它们让效果名变成“带图标的密集列表”，反而降低检索效率。

现在：

- 删除底部预览卡和整个 `CompEffectPreview` 渲染器；
- 删除逐行缩略图与 26 px 缩进；
- 列表直接使用 BBS 原生列表行，行高从 14 px 提高到 17 px；
- 列表高度从 `1F-142` 增加到 `1F-88`，分类/搜索/应用按钮仍固定在底部；
- 双击效果名仍然应用，底部“应用效果”仍然保留。

结果：同样的左侧栏能多显示约 3 行，分类标题和效果名成为唯一视觉层级。

## 2. BBS 摄像机操作提示

BBS 原版影片编辑器的右键拖动旋转镜头；本合成器的预览右键拖动是 **3D 视口环绕**。直接改掉
会把视口导航弄坏，因此保留现有手势，并把差异说明放在三处：

- 摄像机检查器的 BBS 模式说明；
- 切到 BBS 摄像机时的状态栏提示；
- 预览信息栏常驻：`BBS 相机：F 飞行 / 右键=视口环绕`。

要旋转 BBS 镜头：按 **F** 进入飞行，用鼠标转向；再按 **F** 退出并在当前位置写关键帧。

## 3. 赞助只在设置里

赞助不是剪辑工作流的一部分，也不再出现在主剪辑页：

- 删除头部“赞助”按钮；
- 删除全屏 `UISponsors` 覆盖层；
- `UICompSettings` 新增“赞助者”分类，内容是一块嵌入滚动区域的 `UISponsorBoard`；
- 每个赞助者下面只有一句“感谢你的支持。”，不再写激励文案、层级或口号；
- 保留金色轨道、光束、粒子、卡片 hover 等高级光效，但限制在设置卡内。

## 4. 新手引导背景

引导页的卡片几乎不透明，原来的 BBS 背景大部分被卡片盖住。新增
`UIOnboarding.renderPremiumBackdrop()`，在卡片后面叠加：

- 左下暖金、右上冷蓝两团缓慢漂移的极光；
- 四条低频斜向光束（MatrixStack 旋转，不引入新 GL 状态）；
- 两圈极淡的椭圆结构线；
- 34 个缓慢上升的尘埃粒子；
- 底部渐晕。

全部只在 `glow`/`backdropIntensity` 开启时绘制；关闭动效时完全静态。

## 5. 主剪辑界面的高级化

- 主面板底色从单一 `0xFF0E1116` 改为深蓝黑纵向渐变；
- 顶部左右各一团极低透明度 accent 光池；
- 底部 36 px 内阴影分隔时间轴；
- 预览区四角增加细角标（四组短线），飞行模式时顶边出现一条冷蓝线；
- 没有任何效果遮住文字、时间轴或预览画面，成本是少量 batched quads。
