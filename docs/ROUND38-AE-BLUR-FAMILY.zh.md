## 1. 为什么不直接铺 200 个名字

你列出的目录包含几类完全不同的东西：

| 类别 | 本质 | 本工程现状 |
|---|---|---|
| 模糊/锐化、色彩、扭曲、生成、风格化、过渡 | 单输入全屏 shader + 参数 | 可逐族实现 |
| 通道/算术/混合、纯色合成 | 需要**下层图层**作为第二输入 | 需要把 accumulation 传给效果 |
| 时间（回声、时间混合、时间置换） | 需要**历史帧缓冲** | 需要时域缓存 |
| 3D 通道、Cryptomatte、EXtractoR、ID 遮罩 | 需要 G-buffer 的 ID/EXR 通道 | 当前只有世界深度 |
| 音频（EQ、混响、压缩、延迟…） | 独立 **DSP 图**，不是 GPU pass | 需要音频引擎 |
| 粒子、泡沫、雨雪、碎片 | **粒子/模拟引擎** | 需要独立模拟器 |
| Mocha、3D 摄像机跟踪 | **跟踪/求解器** | 需要独立求解器 |
| 表达式控制、图层控制、源文本 | 属性/UI 控制器，不是像素效果 | 属于表达式系统 |

把它们全部塞进一个渲染 switch 只会得到“名字存在、画面不对”的假实现。所以按族推进，
每一批都必须真的能出画面、能被关键帧、能在 2D/3D 路径工作。

## 3. 新着色器 `AE_BLUR`

一个程序、七种模式：

0. **交叉模糊**：横/竖两个方向的 17 抽样，权重 `(1-t)^2`；
1. **径向快速模糊**：从中心向当前像素的 8 抽样，强度是 0..1 的比例；
2. **镜头/散景模糊**：24 个黄金角圆盘抽样，均匀权重；
3. **通道模糊**：R/G/B 各自半径（`radius_g`、`radius_b`），alpha 用基础半径；
4. **复合模糊**：用源亮度作为模糊量贴图，`softness` 控制贴图影响；
5. **双边/智能模糊**：5×5 邻域，空间高斯 × 颜色差高斯；`threshold` 是颜色容差；
6. **USM/抖动去模糊**：四邻域模糊求细节，`threshold` 过滤低对比细节，`amount` 控制增强。

### 预乘 alpha

对称核在直通 alpha 上采样会把边缘外的黑色拉进来。`aeBlur` 先用
`PassRenderer.premultiply` 转预乘，运行 shader，再用 `unpremultiply` 转回；整个效果族只
多两次全屏 pass。

### 与既有系统集成

- **强度**：所有新效果自动获得 `global_strength`（0 = 原图层）；
- **中性值**：radius ≤ 0 或 amount = 0 时直接返回输入，不启动 pass；
- **3D 支持域**：`EffectPadding` 为新效果预留半径，发光/模糊不再在图层矩形处裁断；
- **代理分辨率**：`scaleEffectForRaster` 把半径从图层像素换算成栅格像素，视觉半径不变；
- **单次应用**：3D 层仍由源缓存烘焙，组合阶段跳过非深度效果。

## 5. 下一批路线

按“单输入 shader 族”优先，能把数量和质量同时推进：

1. **扭曲**（36 项）：在现有 `DISTORT` 上加偏移、极坐标、球面化、光学补偿、镜像、变换、
   贝塞尔/网格变形；其中 CC 系列是同一族的参数预设。
2. **生成**（22 项）：四色渐变、填充、椭圆、光束、镜头光晕、分形、无线电波、书写/涂鸦、
   音频频谱/波形（需要音频采样）。
3. **风格化 + 过渡 + 抠像 + 噪点**（约 40 项）：扩展 `PIXEL`/`TRANSITION`/`KEY`/`NOISE`。
4. **通道 + 色彩校正**（17 项）：先把 accumulation 作为第二输入传给效果，再做算术/混合/
   设置通道/纯色合成；色彩校正可复用 `COLOR` 的完整参数。
5. **时间**（8 项）：历史帧缓冲 + 时间重采样。
6. **3D 通道**（9 项）：需要 ID/对象缓冲、EXR 通道；深度遮罩/雾/景深已有基础。
7. **音频**（13 项）：独立 DSP 图，离线处理 `CompAudioMixer` 的混合结果。
8. **模拟**（15 项）：粒子/流体/碎片引擎。
9. **透视/跟踪**（12 项）：投影、径向阴影可先做；Mocha/摄像机跟踪需要求解器。
