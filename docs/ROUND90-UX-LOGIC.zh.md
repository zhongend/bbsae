## A. 蒙版工作流

### 问题

`applyMatteToBelow` 为了不让源形状的填充盖住目标，会设置 `source.visible=false`，然后把
选择跳到目标。结果：

- 用户看不到源形状；
- 想改蒙版形状时必须滚动时间轴找隐藏层、点眼睛；
- 没有“当前谁是蒙版来源/目标”的明确返回路径。

### 修改

- 目标层蒙版页新增：
  - `编辑蒙版来源`：选中源形状并临时 `visible=true`，可直接改形状/位置/颜色；
  - `显示来源` / `隐藏来源`：不改变 matte 关系，只切换可见性；
  - “编辑完成后用‘隐藏并返回目标’恢复合成画面”提示。
- 源形状蒙版页新增：
  - `返回蒙版目标`；
  - `隐藏来源并返回`：隐藏源并选中目标，恢复干净画面。
- 切换选中图层时重置 `maskAdvancedExpanded=false`，避免高级路径蒙版展开状态串层。

限制：编辑来源时源形状会临时绘制在目标上（填充可见），这是有意的可视编辑模式；
点“隐藏来源并返回”即恢复。没有改 matte 的所有权/渲染语义。

## B. 预合成 / 多选 / 3D 入口

- 多选检查器的 `合成预渲染` 实际调用 `precomposeSelection`（预合成），命名误导；改为
  `预合成所选`，tooltip 说明“移入子合成，保留 3D 相机/位置，可 Ctrl+Z”。
- 时间轴右键预合成层新增 `进入预合成`；之前只能到检查器预合成区找“进入预合成”。
- 预合成完成状态由“合成预渲染”改为“移入预合成”，并提示右键进入。
- `CompStore.precompose`（单层）复用 `CompLayerOps.inheritActiveCamera`，与多选
  `CompLayerOps.precompose` 一样复制父级活动摄像机、关键帧、in/out 时间 rebase。
- 折叠变换仍在预合成页；本轮不重排它，避免改变已选的低风险范围。

## C. 布局 / 检查器

- `锁定面板布局` 从 设置 → 开发者 移到 设置 → 布局（工作区预设/控件密度旁）。它与顶栏
  「布局」按钮仍调用同一 `isDockLayoutLocked/setDockLayoutLocked`。
- 蒙版模式按钮从“相加”改为 `模式：相加 ▾`，并加 tooltip：左键循环、右键选择全部 8 种。
- 形状层批量颜色从“形状颜色（全部形状）”改为“全部形状填充色（快捷）”，明确它只改
  fillColor，逐形状渐变/描边仍在形状页。
- 切换图层重置高级蒙版展开状态。

## D. 时间轴 / 快捷键

- 新增右键 `进入预合成`（仅预合成层且 precompId 非空）。
- 统一“预合成”命名：多选按钮、右键菜单、完成状态。
- 没有改快捷键映射；`Delete`、`Ctrl+D`、`Ctrl+Z` 等既有动作保持。

## E. 蒙版模式 / 形状

- 8 种蒙版模式（Add/Subtract/Intersect/Exclude/Lighten/Darken/Difference/None）已在上一轮
  实现；本轮把按钮明确标成 `模式：... ▾`，右键菜单仍是完整列表。
- 形状批量填充色标签明确为“快捷”，减少和逐形状 `填充颜色` 的混淆。
